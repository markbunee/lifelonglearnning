# wsl
## 配置wsl
```python
启用wsl服务：
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart  

启用虚拟机平台
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart  

重启电脑

wsl2性能更强所以使用这个为默认版本
wsl --sety-default-version 2
查看官方支持列表
wsl --list --online
安装指定版本
wsl --install -d Ubuntu-22.04
导出镜像备份
wsl --export 名称 路径.tar
卸载发行版
wsl --unregister

当wsl占用较多内存：
在windows用户目录下创建.wslconfig文件来限制

$config = @"
[wsl2]
memory=4GB
processors=2
"@
$config | Out-File -FilePath "$env:USERPROFILE\.wslconfig" -Encoding ascii

在cmd开启的命令：
wsl --status
wsl --list --verbose 查看发行版 可以缩写 -l -v
```

## wsl迁移
```python
wsl --shutdown
wsl --export Ubuntu D:\wsl_backup\ubuntu.tar
（将整个发行版导出为一个.tar 文件到临时位置。）
注销原发行版：这将删除 C盘上的原始 VHDX 文件，释放空间。
wsl --unregister Ubuntu
wsl --import Ubuntu D:\wsl\Ubuntu-22.04 D:\wsl\Ubuntu-22.04\ubuntu.tar --version 2
（将 .tar 文件导入到 D 盘的目标文件夹，这将创建新的 VHDX 文件。）
```

# 挂后台指令
```python
1）nohup：
nohup uvicorn server:app --host 0.0.0.0 --port 8123 > server.log 2>&1 &
nohup python3 -u intrusion_app_mq.py > 261021.txt 2>&1 &

nohup：核心指令。告诉系统：忽略 HUP（挂断）信号。

python3 -u：执行 Python。-u 极其关键，它代表 "unbuffered"（不缓存）。如果不加 -u，Python 
的输出会先存在内存里，你用 tail -f 观察日志时会发现半天没动静，加了它就能实时看到日志。

> 261021.txt：将标准输出（程序的正常 log）重定向到这个文本文件。

2>&1：将标准错误（报错信息）也合并到同一个文件中。
这样不管是正常运行还是崩溃，你都能在 261021.txt 里找到原因。

&：在命令最后，表示将任务放到后台运行，让你能继续输入其他命令。

查看挂后台的指令：ps -ef | grep python3
```

## vim的指令
在使用指令前，必须搞清楚你现在在哪：

1. **普通模式 (Normal Mode)**：默认进入的状态。此时键盘是“功能键”，不是用来打字的。
2. **编辑模式 (Insert Mode)**：用来打字。按 `**i**` 进入。
3. **命令模式 (Command Mode)**：用来保存、退出。按 `**:**` 进入。

1) 在**普通模式**下输入：  

`**i**`

**进入编辑模式**（在光标前开始输入文字）

`**Esc**`

**退出编辑模式**，回到普通模式

`**:w**`

**保存** (write)

`**:q**`

**退出** (quit)

`**:wq**`

**保存并退出** (常用)

`**:q!**`

**强制退出，不保存** (改乱了救命用)

2）快捷键普通模式之下

移动与跳转

+ `**gg**`：跳到文件**开头**。
+ `**G**`：跳到文件**末尾**。
+ `**0**` (零)：跳到当前**行首**。
+ `**$**`：跳到当前**行尾**。
+ `**行号 + G**`：跳转到指定行（如 `10G` 跳转到第 10 行）。

删除与撤销

+ `**x**`：删除光标处的**单个字符**。
+ `**dd**`：删除（剪切）**当前整行**。
+ `**dG**`：从当前行删除到文件末尾（清空配置常用）。
+ `**u**`：**撤销**上一步操作 (Undo)。
+ `**Ctrl + r**`：**重做** (Redo)。

复制与粘贴

+ `**yy**`：复制当前行。
+ `**p**`：在光标后方**粘贴**。

3）搜索与替换

+ `**/关键词**`：向下搜索。按 `**n**` 找下一个，按 `**N**` 找上一个。
+ `**:set nu**`：显示行号。
+ `**:set nonu**`：隐藏行号。

### 不小心Ctrl+Z
```python
fg 快速吧最近一个挂起的任务转回到前台
jobs 查看后台有多少挂起的程序
fg %2 恢复第二个

千万别直接关掉终端：如果你直接关闭堡垒机窗口，后台挂起的程序可能会被强制杀死，你没保存的内容就真丢了。
不要重复打开新文件：很多新手发现 Ctrl + Z 之后回到了命令行，就再次输入 vim file。这样会导致产生多个 .swp 交换文件，系统会报错提示“Found a swap file”

```
