# 标点信息需求整理与demo实施方案

1. 一个是我们的会员报告你见过吧，我们想用ai进行着这类型报告的批量生成和更新。包括我们有一些给客户的月度监测报告，有固定模版的也希望用这种方式去生成。

2. 另外基座能否左公网的数据抓取，例如我们要更新医院的分级床位数门诊量等信息，如果到大量的医院官网去查。这部分能否由ai执行

3. 另外我们有些批文和药品审评和招投标的数据库，需要建立一个智能体从我们自己的数据库里面采集正确的数据生成答案给客户，这方面目前公网的ai存在很大缺陷，回答的信息有很多编造和幻觉。例如让ai回答某个药目前有多少个批文多少厂家，往往都是ai编造的数据 --ok

4. 这个是我们目前给客户提供的一个药品审评周报的服务，这个我们目前的做法是 先人工统计表格后，然后用ai辅助生成文字表述的内容，但是目前存在一个问题就是AI生成的内容没有稳定固定格式，每次都会有一些变化，所以看看能不能以一份报告为基准，其他报告都能生成相同内容的格式譬如说以药品审评周报202605，对其他报告的第一部分的分析内容进行统一格式的内容生成。 第二个是目前数据表格是人工整理的，能否让ai对统计的表格进行统计生成。
